# AWE System — CPS Open Day Poster (A0)

Poster presented at the **Center for Preparatory Studies (CPS) Open Day**, Spring 2026.
Format: **A0 portrait** (841 × 1189 mm) at 150 DPI — 4967 × 7022 px.

## Files

| File | Description |
| --- | --- |
| `AWE_System_Poster_A0_editable.psd` | Layered poster, editable in Photoshop — 132 layers, all copy is live text |
| `AWE_System_Poster_A0.png` | Flattened full-resolution export for printing / sharing |
| `AWE_System_Poster_A0_preview.jpg` | Half-size preview for quick viewing |
| `AWE_poster_fonts.zip` | Fonts used in the poster (Montserrat, Source Sans 3) |

## Editing the PSD

- All headings and body copy are **live text layers** (layers named `T01`–`T77`, kind "Type") — edit them directly with the Type tool, no re-drawing needed.
- Backgrounds, cards, chips, icons, QR codes and the SQU logo are separate pixel layers and can be moved, recoloured or hidden independently.
- **Install the fonts from `AWE_poster_fonts.zip` before opening the PSD** so the text renders exactly as designed (both fonts are free, SIL Open Font License).
- The canvas is A0 portrait at 150 DPI; use *Image → Image Size* if you need a different output size.
